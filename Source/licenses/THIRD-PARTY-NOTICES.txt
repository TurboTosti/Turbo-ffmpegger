Native portable launchers
The Windows launcher uses only built-in Windows API DLLs. The Linux launcher
statically links musl; its full notice is in musl-LICENSE.txt. Zig 0.15.2 was
used as a build tool; its notice is in Zig-LICENSE.txt, and Windows SDK/import
definitions from mingw-w64 are covered by mingw-NOTICE.txt. The compiler and
its build cache are not included in the application packages.

FFmpeg and FFprobe — user-supplied conversion programs, not distributed here
https://ffmpeg.org/download.html
Neither platform package includes these command-line programs. The user
supplies a matching pair in App/resources/tools. See Help/FFmpeg-setup.md.
Their license terms depend on the build the user obtains. The application
source archive is not corresponding source for those external programs.

Electron's ffmpeg.dll (Windows) / libffmpeg.so (Linux) is a separate runtime
library and remains included. Its applicable notices, along with other
Chromium components, are retained in Chromium-LICENSES.html. These runtime
libraries must not be replaced by conversion tools from another build.
